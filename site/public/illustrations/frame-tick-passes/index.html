    How to read this
    • Left: the passes of one tick in the order the server runs them. The drain comes first, between ticks; the tick raises the frame counter, then runs ranks 1 to 20.
    • Right: what the current pass is and which seeds it can draw on, as the server frame page states them. A frame in which a pass has nothing to do leaves its seeds as they were.
    • Ranks 17 to 19 run on frames that divide by 20, 12 and 11; the sweep of rank 20 runs every frame but works only when the counter divides by 1500.
    • The pass list is drawn from the spec, not computed by a model of the tick; the only computed values are the divisibility tests on the frame number given.
