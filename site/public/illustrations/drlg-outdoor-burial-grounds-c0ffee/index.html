    How to read this
    • The grid is the level cut into cells of 8 * 8 tiles; each box is one cell, D is the piece number, I the file index.
    • First the outline ring and the seam mark, then the border pass walks the ring and puts an edge piece on each cell and a corner piece at each turn.
    • The first use of a piece in the level draws a start for its file rotation; the pieces then take the next file in turn.
    • Every value is computed by our model of the outdoor generator for the illustrative seed given, not observed in the game.
