    How to read this
    • Left: the tests in the order the game runs them. The current test is outlined; a won test ends the roll, a lost one passes to the next.
    • Right: the chance c of the current test, in four steps (base term, magic find, the row's minimum, the ratio word), then the draw. A draw below 128 wins; a c below 1 wins with no draw.
    • The superior and normal tests use only the base term. A test with no draw changes nothing on the seed.
    • Every value is computed by our model of the roll for the illustrative inputs given, not observed in the game.
