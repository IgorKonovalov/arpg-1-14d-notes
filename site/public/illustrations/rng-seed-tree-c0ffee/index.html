Calculations for this step
    How to read this
    • Top: the map seed (it builds the world) and the game seed (it seeds the units); both start from the same number N when the game is made with an override.
    • Second row: one box per act. Every act starts from the map seed, steps once, and keeps that low word as its level seed base.
    • Third row: each level's seed is the act's base plus the level id, a sum with no draw.
    • Bottom row: each room takes one draw from its level's seed, starts its own seed from the result and steps once.
    • Every value is computed by our model for the illustrative seed given, not observed in the game.
