Calculations for this step
    How to read this
    • Top: the seeds. The game seed is started with Init and drawn once; the region seed is made from that draw, and every level's pool is drawn on it, one level after another.
    • Candidates: the level's monster slots up to the first blank. Each pick draws over the candidates that remain, takes one, and removes its slot, so a slot is never taken twice.
    • A taken class is kept only if it may spawn; its rarity is copied to the pool and used later, when a room picks from it.
    • Every value is computed by our model for the illustrative seed, not observed in the game.
