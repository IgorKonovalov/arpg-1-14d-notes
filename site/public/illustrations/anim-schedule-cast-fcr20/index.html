Calculations for this step
    How to read this
    • Top row: the game frames after the mode starts at T. The scan runs once, when the mode starts, and takes one step for each game frame ahead; the end fires one frame after the last step.
    • Middle row: the animation's own frames. The marker is the position in 1/256 of a frame, it advances by the rate r each step; a frame event queues on the step whose position has passed its frame.
    • The rate comes from the record's speed and a speed bonus; the length of the mode is the record's 256 F divided by r, rounded up, and at least 2.
    • The record is a toy given by its numbers, not a table row. Every value is computed by our model for the numbers given, not observed in the game.
